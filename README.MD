# Tic Tac Toe Game

A simple and interactive two-player Tic Tac Toe game built using HTML, CSS and JavaScript.

## Features
- Two Player Gameplay (X and O)
- Winner Detection
- Draw Detection
- Scoreboard
- Restart Game
- New Game
- Sound Effects
- Voice Congratulations
- Black and White Theme
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
